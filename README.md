# Challenge-06---Pattern-detective-

Problem Read N activity readings into a one-dimensional array and complete every task below. N must be between 5 and 12 inclusive. Each
reading must be an integer from 0 to 1000 inclusive. If N or a reading is invalid, ask again until valid input is entered.

Algorithm 

1.Start.
2.Read the number of readings N. If N is less than 5 or greater than 12, ask again.
3.Read N integer readings. If any reading is outside the range 0–1000, ask again for that reading.
4.Calculate the sum, average, minimum, and maximum of the readings.
5.Find the second-largest distinct value by finding the largest value smaller than the maximum. If it does not exist, display a message.
6.Count local peaks. A local peak must be greater than both its immediate neighbours.
7.Find the longest continuous strictly increasing run in the original sequence.
8.Read the rotation value K. Normalize K to a value between 0 and N − 1.
9.Rotate the array right by K positions using reversal, without using a second array.
10.Read the last two digits R of the registration number.
11.Calculate the personal divisor using D = (R % 9) + 1.
12.Count the readings in the rotated array that are exactly divisible by D.
13.Display all results.
14.Stop.
